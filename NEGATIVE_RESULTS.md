# Negative results

## T4

The frozen T4 experiment did not demonstrate that shared canonical state alone improves decision quality over the supplied API comparator. A later causal audit aligned 1,000 paired lives and 600,000 events and found no divergence in the control projection while communication and process metrics differed.

The comparator was not a causally independent modular intelligence: it shared the same trial state, policy, reflexes, authority, and action logic, and its API response did not feed back into action selection. Therefore T4 is simultaneously:

- a valid negative result for the narrow frozen implementation;
- a construct-validity failure for the broad non-separability claim;
- not evidence that the broad OASI thesis is true;
- not a refutation of every future organismic mechanism.

The reflex implementation reduced cognitive calls but increased regret and damage in the frozen task. This failure is preserved because removing it would misstate the research record.
