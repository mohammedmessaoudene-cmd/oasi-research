# OASI v0.3 — Results Insertion Protocol

The manuscript is structurally closed except for future evidence admitted through Appendix A.

## Required terminal evidence

A candidate report must include:

- ZIP name, exact size, and SHA-256;
- immutable generation and source-manifest digest;
- A/B build identities and terminal receipts;
- deterministic artifact comparison;
- QEMU and guest identities;
- complete gate catalog with per-gate evidence hashes;
- Review A, Review B, and red-team results on the same generation;
- authority boundary and no-replay status;
- explicit statements for Stage6R, Stage7, performance interpretation, and scientific authority;
- a claim delta naming the exact sentences, equations, tables, and figures that may change.

## Allowed outcomes

- `INSERT_BOUNDED_ENGINEERING_RESULT_ONLY`
- `INSERT_REPRODUCIBLE_GUEST_FIXTURE_RESULT`
- `HOLD_EVIDENCE_INCOMPLETE`
- `NO_GO_CLAIM_EXCEEDS_EVIDENCE`

## Prohibited promotions

- Build success -> organismic intelligence
- QEMU boot -> developmental closure
- Gate count -> scientific superiority
- Hash integrity -> semantic truth
- Internal review -> institutional independence
- Failure recovery -> biological self-healing
