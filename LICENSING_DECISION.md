# Strategic licensing decision for OASI v0.1 and v0.2

- Historical Rust source and tests: **`Apache-2.0 OR MIT`**.
- New original standalone project tools and schemas: **`Apache-2.0`**.
- Article, figures, specifications, documentation, and public evidence summaries: **`CC-BY-4.0`**.
- Third-party material: its original license only.
- OASI name and logo: project and trademark rights reserved; no registration claimed.

The same path-specific map applies to the v0.2 publication additions: original
experiment Python code is Apache-2.0, while protocols, sealed result data,
article material, and explanatory documentation are CC-BY-4.0. The exact map is
recorded in `LICENSE_INVENTORY.json`.

AGPL is not applied retroactively to v0.1 or v0.2. A future clean-slate OASI runtime may use `AGPL-3.0-only` only after a fresh chain-of-title, contributor, and compatibility review. No commercial dual license is claimed for v0.1 or v0.2.
